遊び方 — How to play (translated from Oh!FM 1984):
• Move with Arrows / Numpad 7-9-1-3 (テンキー).
• Touch foe → grapple (組み合い). Then mash BREAK key — here SPACE / B / tap button — as many times as you can in 2 sec! (連打！)
• More mashes = stronger move. Press 0 / Enter to execute (０キーで技をかける).
• 0 near downed foe = pin (フォール) / tag (タッチ). Pin to 3-count to win.
• Moves cost stamina (スタミナ). Rest by keeping distance.
Original: BREAK key = ESC on emulator. Moves flash on screen. Damage scales with mash count.
